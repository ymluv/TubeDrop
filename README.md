# TubeDrop

TubeDrop - десктопная программа для скачивания видео и аудио через `yt-dlp`.

Поддерживаются:

- YouTube;
- TikTok;
- Instagram;
- Pinterest;
- Twitch: видео, клипы, записи трансляций и другие ссылки, которые поддерживает `yt-dlp`.

Приложение работает локально на вашем ПК, сохраняет выбранные настройки между запусками и ведет историю скачиваний с превью.

## Запуск

### Готовый exe

1. Скачайте `TubeDrop-windows-x64.zip` из Releases.
2. Распакуйте архив.
3. Откройте `TubeDrop.exe`.

Python и зависимости устанавливать не нужно.

### Из исходников

1. Откройте `run.bat`.
2. Дождитесь запуска приложения.

При первом запуске создается `.venv` и устанавливаются зависимости из `requirements.txt`.
После запуска приложения окно `cmd` закрывается.

Для запуска из исходников нужен Python 3.10+.

## Использование

1. Вставьте ссылку.
2. Нажмите `Получить`, чтобы загрузить информацию о видео.
3. Выберите качество.
4. Выберите папку.
5. При необходимости введите имя файла.
6. Нажмите `Скачать`.

Если поле имени файла пустое, используется автоназвание:

```text
название видео [id]
```

Кнопка `Отмена` останавливает текущее скачивание.

После завершения доступны кнопки:

- `OK`;
- `Открыть файл`;
- `Открыть папку`.

На главной кнопке используется двухэтапный сценарий:

- без ссылки кнопка неактивна;
- после вставки ссылки кнопка становится `Получить`;
- после загрузки информации кнопка становится `Скачать`;
- при вставке новой ссылки процесс снова начинается с `Получить`.

## История скачиваний

Вместо журнала логов в приложении показывается история скачиваний.

- История отображается сеткой в 3 столбца.
- У каждого элемента есть превью, логотип источника и дата скачивания.
- Кнопка `Открыть` запускает скачанный файл.
- Кнопка `Папка` открывает папку в Проводнике и выделяет нужный файл.
- Корзина на превью удаляет элемент только из истории, сам файл не удаляется.

## Форматы

- Видео сохраняется в MP4.
- Instagram-видео автоматически подготавливается как H.264/AAC MP4, чтобы видеоряд корректно открывался в Vegas.
- Для видео используется AAC-аудио: 192 kbps, 48 kHz, stereo.
- Доступные аудиоформаты: M4A, MP3, WAV.
- MP3 сохраняется как 192 kbps CBR, 48 kHz, stereo, ID3v2.3.
- Превью видео сохраняется в ту же папку.

Опция `MP4 для Vegas` принудительно готовит H.264/AAC MP4 и может увеличить время подготовки файла.

## Вход в сервис

Если YouTube, TikTok, Instagram, Pinterest или Twitch требует вход или проверку:

1. Нажмите `Проверка`.
2. Нажмите `Открыть вход`.
3. Войдите в нужный сервис в открывшемся браузере.
4. Вернитесь в приложение.
5. Нажмите `Готово`, не закрывая окно браузера входа.

Используется отдельный профиль браузера TubeDrop.
После входа TubeDrop сохраняет снимок cookies и использует его для скачивания.

Для Instagram TubeDrop может сразу предложить вход до получения информации, если сохраненной сессии еще нет.
После нажатия `Готово` приложение ждет сохранения cookies и автоматически повторяет запрос.

## Настройки и локальные файлы

Настройки, история и служебная сессия сохраняются рядом с запущенным приложением.
Для exe-сборки это папка, где лежит `TubeDrop.exe`.

Основные файлы и папки:

```text
tubedrop_state.json
history_thumbnails\
.tubedrop_profile\
.tubedrop_secure_browser\
```

`tubedrop_state.json` хранит выбранную папку, имя файла, качество, состояние опций и историю скачиваний.
`history_thumbnails` хранит локальные превью для истории.
Служебные папки профиля браузера нужны для входа в сервисы.

Кнопка `Сброс` удаляет сохраненную сессию.

## Сборка exe

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

Результат:

```text
dist\TubeDrop.exe
dist\TubeDrop-windows-x64.zip
```

В exe включены Python, PySide6, `yt-dlp`, Node.js и ffmpeg.
Иконка приложения собирается из `assets\tubedrop.ico`.

## Совместимость

Поддерживается:

- Windows 10 x64;
- Windows 11 x64.

Не является готовой версией для:

- Windows 7/8/8.1;
- Linux;
- macOS.

## Зависимости

- `yt-dlp`;
- `yt-dlp-ejs`;
- `nodejs-wheel-binaries`;
- `PySide6`;
- `Pillow`;
- `requests`;
- `imageio-ffmpeg`.
